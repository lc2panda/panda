## §2 设计语言（来源：A1 · B1 · C1 §2/§5 修正）

### 2.1 设计哲学

七词调性锚（B1 §1.1）：

| # | 关键词 | 含义 | 来源 |
|---|---|---|---|
| 1 | **Warmth（温暖）** | 反 clinical blue，用奶油底 + 赤陶橙 | A1 §2.1 brand-guidelines |
| 2 | **Editorial（编辑感）** | sans/serif 混排 + 大留白 + 排版精度 | A1 §2.2 Styrene + Tiempos |
| 3 | **Restraint（克制）** | 反炫技、反过度动效 | A1 §2.5 dialohg 反例 |
| 4 | **Companionship（陪伴感）** | Panda 品牌灵魂；桌宠 + mini-avatar + BuddyEventCard 三层 | A3 §4.5 XP/等级养成 |
| 5 | **Healing（治愈）** | 圆角 ≥ 6px + 柔和阴影 + 呼吸节律（scale 1↔1.035） | A3 §3.2 APNG idle 规格 |
| 6 | **Focus（专注）** | 内容优先 + 工具调用默认折叠 + 单列阅读流 | A2 §7.2 tool_group |
| 7 | **Trust（可信）** | 权限透明 + PermissionMode chip 常驻 + ToolResult 永不 hide | A1 constitutional/safe |

5 条设计原则（B1 §1.2）：
1. **Warm but Restrained**：playful ↔ enterprise 两难时，选后者 + 一丁点温度。圆角 ≤ 16px、阴影 ≤ 3 层、动效 ≤ 300ms、插画单色线稿。
2. **Content-First**：屏幕像素 ≥ 70% 是用户真实内容；每个视觉装饰必须回答"它是否帮用户更快读内容"。
3. **Keyboard-Native**：所有高频操作必须有键盘路径；所有菜单/模态支持 ↑↓+Enter+Esc 闭环。
4. **Permission-Visible**：永久可见的权限模式 chip + 永不 hide 的拒绝历史。
5. **Pet is Companion, not Hero**：mini-pet ≤ 32px；空状态插画 ≤ 160px；主内容区永不被占据。

### 2.2 色彩系统（WCAG 2.2 AA 合规修正后）

#### 2.2.1 ⚠️ C1 §2 K9 修正后的合规色板（亮色）

#### 3.6.1 流式节流（B2 §5.2 · 借鉴 A2 §5.3 cc-haha `chatStore.ts:112-114`）

```ts
// 每 16ms flush 一次，避免 per-token re-render
const pendingDelta: Record<string, string> = {}
let flushTimer: ReturnType<typeof setTimeout> | null = null

function scheduleFlush() {
  if (flushTimer) return
  flushTimer = setTimeout(() => {
    useChatStore.setState(state => {
      for (const [id, delta] of Object.entries(pendingDelta)) {
        const s = state.sessions[id]
        if (s) s.streamingText += delta
      }
      return { ...state }
    })
    Object.keys(pendingDelta).forEach(k => delete pendingDelta[k])
    flushTimer = null
  }, 16)
}
```

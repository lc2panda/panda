## 核心发现

### 根因
**上下文污染导致的格式模板混乱**

Agent在长时间运行后（23k+ tokens，34分钟），错误地使用了不存在的`raw`参数，并将工具参数JSON序列化为字符串。

### 错误格式
```json
// ❌ 错误（agent实际使用）
{
  "name": "Write",
  "input": {
    "raw": "{\"file_path\": \"/path/to/file\""
  }
}

// ✅ 正确
{
  "name": "Write",
  "input": {
    "file_path": "/path/to/file",
    "content": "file content"
  }
}
```

### 影响
- 17次连续失败
- Agent意识到错误但无法修正
- 任务被完全阻塞
